This release delivers significant performance improvements including ORDER BY with LIMIT pushdown through joins (up to 20x faster) and a new filesystem table function for querying local file systems with SQL. The update also introduces GROUP BY with LIMIT optimization, multi-path SQL/JSON support, and an experimental web terminal, along with 38 new features and 51 performance optimizations overall.
