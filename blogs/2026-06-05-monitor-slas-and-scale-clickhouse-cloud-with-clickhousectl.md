This guide demonstrates how to tag queries with SLA targets, then use the clickhousectl CLI tool to investigate performance breaches by querying system logs and metrics. The article shows both manual scaling approaches and how to delegate investigation and remediation decisions to an AI agent, which can analyze the root cause and apply appropriate infrastructure adjustments.
